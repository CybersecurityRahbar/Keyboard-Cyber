# Keyboard Cyber

لوحة مفاتيح Android عربية/إنجليزية مع أرشيف حافظة محلي دائم، مصممة بواجهة داكنة مستوحاة من أدوات الأمن السيبراني.

## ما الذي بدأ تنفيذه؟

- مشروع Android أصلي بلغة Kotlin.
- خدمة لوحة مفاتيح حقيقية عبر Android `InputMethodService`.
- تخطيط أولي عربي وإنجليزي مع الأرقام والرموز والإيموجي.
- قاعدة SQLite محلية تحفظ كل عملية نسخ تلتقطها لوحة المفاتيح، دون حدّ سجلات أو حذف تلقائي.
- بحث داخل الأرشيف، نسخ السجل مجدداً، والمفضلة.
- شريط اقتراحات مصدره النصوص المنسوخة فقط، ويمكن إيقافه من التطبيق.
- استبعاد الحقول المعروفة كحقول كلمات مرور، واستبعاد محتوى الحافظة الذي يضع النظام عليه علامة الحساسية.

## البناء

يتضمن المستودع Gradle Wrapper الرسمي 9.7.0 مع بصمة SHA-256 لتوزيعة Gradle. افتح المجلد في Android Studio أو شغّل:

```bash
./gradlew assembleDebug
```

على Windows:

```bat
gradlew.bat assembleDebug
```

## التفعيل على الهاتف

1. ثبّت التطبيق.
2. افتحه واضغط «تفعيل اللوحة».
3. فعّل Cyber Keyboard من إعدادات النظام.
4. ارجع للتطبيق واضغط «اختيار الافتراضية» ثم اختر Cyber Keyboard.
5. اختبر النسخ من تطبيق آخر.

يجب اختيار Cyber Keyboard كلوحة افتراضية حتى تستفيد من استثناء Android المخصص للوحات المفاتيح في قراءة الحافظة. مجرد تشغيل خدمة خلفية عادية لا يمنح هذا الوصول.

## الوضع الحالي

هذا أول إصدار تأسيسي وليس إصداراً نهائياً. العربية والإنجليزية هما التخطيطان المدمجان حالياً. دعم لغات إضافية، الترجمة السحابية، تصدير/استيراد النسخ الاحتياطية المشفرة، والتصنيفات المتقدمة مراحل لاحقة.

الترجمة مخطط لها عبر الإنترنت دون تنزيل حزم محلية. لن نضع مفاتيح API سرية داخل APK أو المستودع؛ يجب اختيار مزوّد آمن ونقطة اتصال HTTPS قبل تفعيل الترجمة الفعلية.

«دون حدود» تعني عدم وضع سقف برمجي لعدد السجلات وعدم حذف الأقدم تلقائياً. السعة الفعلية تظل محدودة بمساحة تخزين الهاتف.

## الخصوصية

النصوص تبقى محلياً في قاعدة SQLite داخل مساحة التطبيق. الإصدار الحالي لا يرفع محتويات الحافظة إلى خادم. لا يلتقط حقول كلمات المرور المعروفة ولا محتويات الحافظة الموسومة من النظام كمحتوى حساس.
